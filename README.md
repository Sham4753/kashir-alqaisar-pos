# كاشير قيصر — نقطة بيع للمطاعم

نظام كاشير قيصر محلي يعمل دون إنترنت لمطاعم الوجبات السريعة والمطاعم داخل سوريا. يتضمن نقطة البيع، إدارة المنيو والمخزون، إدارة الصالة والطاولات، شاشة المطبخ، التقارير، الصلاحيات، القفل السريع، النسخ الاحتياطي، ودعم الطباعة الحرارية.

روابط البدء: [دليل التشغيل العربي](README_AR.md) · [إرشادات وكلاء الكود](AGENTS.md) · [فهرس الوثائق](docs/README_AR.md).

## أبرز الوظائف

تتيح شاشة البيع تسجيل الطلبات السفري والديليفري وطلبات الصالة. تدعم إدارة الصالة فتح طلب على طاولة، إرساله إلى المطبخ، تعديل الطلب، نقله إلى طاولة شاغرة، ثم إغلاقه كفاتورة مدفوعة. تتضمن الواجهة وضعًا داكنًا، وأيقونات مضمّنة، وعملة مركزية تتزامن عبر كل صفحات النظام.

## التشغيل على Windows

1. استخدم حزمة Windows التي سلّمك إياها المورّد؛ لا تحتاج إلى تنزيل مصدر المستودع.
2. شغّل البرنامج، ثم أرسل **Machine ID** الظاهر للمورّد.
3. أدخل **License ID** و**License Key** اللذين يصدرهما المورّد لهذا الجهاز، ثم أنشئ حساب المدير وكلمة مروره.
4. شغّل `Install_CAESAR_Desktop_Icon.bat` مرة واحدة لإنشاء اختصار سطح المكتب.

لتحديث تثبيت قائم، نزّل رابط ZIP التحديث المباشر من المورّد، ثم استخدم `Apply_CAESAR_Update.bat`. لا تستبدل أو تحذف مجلد `CAESAR_Vault`.

اقرأ [الدليل العربي التفصيلي](README_AR.md) للتشغيل اليومي وإدارة العملة والطاولات والطباعة والنسخ الاحتياطي.

## حماية البيانات

يحفظ التطبيق بيانات التشغيل والنسخ الاحتياطية محليًا، ولا ينشرها هذا المستودع. ملف `.gitignore` يستبعد السجلات وبيانات التشغيل والنسخ الاحتياطية وملفات البيئة، بينما تبقى ملفات البيانات النظيفة الموجودة داخل `app/` قالبًا لأول تشغيل فقط.

> لا ترفع مجلد بيانات مطعم فعلي أو ملف يحتوي على كلمات مرور أو مفاتيح أو نسخة احتياطية إلى أي مستودع، حتى لو كان خاصًا.

راجع [دليل التسليم التجاري](COMMERCIAL_DELIVERY_GUIDE_AR.md) لإعداد مفاتيح المورّد وإصدار الرخص، و[دليل التحديث](RELEASE_UPDATE_GUIDE_AR.md) لروابط GitHub اليدوية. المستودع الحالي عام؛ حزمة العميل لا تحتاج إلى استنساخ المستودع.
