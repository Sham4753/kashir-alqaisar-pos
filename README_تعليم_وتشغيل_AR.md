# كاشير القيصر — حزمة المشروع الكاملة

تضم هذه الحزمة مصدر نظام الكاشير المحلي، مصدر تطبيق النادل، نسخة Windows الأساسية، دليل التشغيل، تقرير الجودة، مراجعة الأمان، والمهارة القابلة لإعادة الاستخدام.

## تشغيل Windows

افتح `POS_Source_Clean` وراجع `دليل_التشغيل_الكامل_AR.md`. شغّل نسخة Windows الأساسية أو شغّل الخادم محليًا من مجلد التطبيق بالأمر `python app/server.py`. يبدأ النظام افتراضيًا على `http://127.0.0.1:8080`، ويمكن تغيير المنفذ عبر `QAISAR_PORT`.

## تشغيل تطبيق النادل

افتح `Waiter_Mobile_Source`، ثبّت Node.js وpnpm، ثم نفّذ `pnpm install` وبعدها `pnpm dev`. للتجربة على الهاتف استخدم Expo Go، واجعل الهاتف والكمبيوتر على الشبكة المحلية نفسها، ثم راجع دليل تطبيق النادل لإعداد عنوان الكاشير.

## تحديث وضوح السلة

أصبحت السلة عمودًا جانبيًا أكبر ومستقلًا عن منطقة الأصناف. تظهر العناصر داخل مساحة بيضاء عالية التباين وقابلة للتمرير، وتبقى أزرار نوع الطلب في أعلى السلة، بينما تبقى أزرار الإجمالي والدفع والطباعة والمسح أسفلها. تم تكبير أسماء الأصناف والكميات والإجماليات وتحسين الحدود والتباين.

## اختبار العتاد قبل التشغيل التجاري

اختبر فعليًا الطابعة الحرارية بمقاسي 58mm و80mm، درج النقد، شاشة اللمس، الماوس، قارئ الباركود، واتصال تطبيق النادل عبر LAN. الحزمة النظيفة لا تحتوي على بيانات تشغيلية أو مفاتيح سرية.
