# ترخيص CAESAR POS بتوقيع Ed25519

## التصميم

يتحقق التطبيق دون اتصال من توقيع Ed25519 باستخدام مفتاح عام ثابت في `app/license_public_key.pem`؛ لا يسمح لمتغير بيئة بتغيير مفتاح الثقة. لا يحتوي التطبيق أو حزمة العميل على المفتاح الخاص أو أداة إصدار الترخيص. غياب المفتاح العام أو عدم كونه مفتاح Ed25519 صالحًا يمنع البناء أو التفعيل. الرخصة مرتبطة بـMachine ID وبـLicense ID مشتق منه، وقيمة License Key توقيع Ed25519 بترميز base64url غير مبطن.

## إعداد المورّد مرة واحدة

من PowerShell على جهاز المورّد، وفي جذر نسخة Windows الكاملة:

```powershell
.\python.exe .\tools\create_vendor_keys.py --private-key-path "D:\CAESAR-Keys\caesar-vendor-private.pem"
```

تطلب الأداة عبارة مرور (12 محرفًا على الأقل) وتكتب المفتاح الخاص مشفّرًا إلى المسار الخارجي، والمفتاح العام فقط إلى `app\license_public_key.pem`. احفظ ملف الخاص وعبارة المرور خارج المستودع وفي نسخ احتياطية آمنة منفصلة. لا تغيّر هذا الزوج عند كل إصدار ولا ترفعه إلى GitHub. المفتاح العام آمن للنشر.

## تدوير المفتاح عند الاشتباه في انكشافه

نفّذ ذلك على جهاز المورّد فقط. أنشئ زوجًا جديدًا بمسارات جديدة، واترك المفتاح القديم معزولًا ولا تستخدمه:

```powershell
.\python.exe .\tools\create_vendor_keys.py `
  --private-key-path "C:\CAESAR-Keys\caesar-vendor-private-v3.pem" `
  --public-key-path "$env:USERPROFILE\Desktop\caesar-vendor-public-v3.pem"
```

اختر عبارة مرور قوية من 12 محرفًا على الأقل واحفظها فورًا في مدير كلمات مرور، منفصلةً عن ملف المفتاح. لا ترفع ملف `caesar-vendor-private-v3.pem` أو عبارة المرور إلى GitHub أو المحادثة. ملف `caesar-vendor-public-v3.pem` وحده آمن للمشاركة؛ حدّث `app\license_public_key.pem` به ثم أعد بناء نسخة العميل قبل إصدار تراخيص للزبائن. لا يمكن استعادة عبارة مرور مفقودة لمفتاح مشفّر.

عند تدوير المفتاح، لا تقبل النسخة الجديدة تراخيص موقعة بالمفتاح السابق. أعد إصدار التراخيص اللازمة باستخدام المفتاح الجديد بعد التحقق من تفعيل النسخة الجديدة.

## إصدار ترخيص جهاز

بعد استلام Machine ID من العميل، افتح `tools\Issue_CAESAR_License.cmd` بالنقر المزدوج. أدخل Machine ID عند الطلب، ثم عبارة مرور المفتاح الخاص المحلي عند المطالبة؛ ستعرض النافذة **License ID** و**License Key**. أرسل القيمتين للعميل فقط. لا ترسل المفتاح الخاص أو عبارة المرور. يستخدم المشغّل `C:\CAESAR-Keys\caesar-vendor-private-v3.pem`، ولا يدخل ملف CMD أو مولّد التراخيص في حزمة العميل.

بديل يدوي من PowerShell:

```powershell
.\python.exe .\generate_license.py --private-key "C:\CAESAR-Keys\caesar-vendor-private-v3.pem" --machine-id "MACHINE-ID"
```

يمكن إصدار ترخيص جديد لنفس الجهاز متى لزم؛ إصدار رخصة لجهاز آخر يتطلب Machine ID لذلك الجهاز.

## الانتقال من إصدار HMAC القديم

الإصدارات السابقة المعتمدة على HMAC لا تقبلها النسخة الحالية. قبل التحديث خذ نسخة احتياطية من `CAESAR_Vault`، وأصدر رخصة Ed25519 جديدة لنفس Machine ID. بعد التحديث استخدم شاشة **إعادة تفعيل النظام** وأدخل License ID وLicense Key. تعيد الشاشة حفظ حقول الترخيص فقط؛ لا تهيئ المطعم ولا تستبدل Vault أو قاعدة البيانات أو المستخدمين أو الفواتير. لا تحذف `CAESAR_Vault` ولا تبدأ الإعداد الأولي لمعالجة مشكلة الترخيص.

## حدود الحماية

التوقيع يمنع إنشاء ترخيص صالح دون المفتاح الخاص، والربط بالجهاز يردع إعادة استخدام الرخصة على جهاز مختلف. لكنه ليس حماية مطلقة أمام من يملك المصدر ويعدّله؛ شروط البيع والاستخدام وسياسة نشر المستودع تكمل الحماية التقنية.
