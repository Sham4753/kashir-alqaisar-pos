# تصميم تطبيق النادل — كاشير القيصر

## نطاق الواجهة

التطبيق مصمم للعمل في **اتجاه عمودي 9:16** وعلى هاتف يمسكه النادل بيد واحدة داخل شبكة المطعم المحلية. يعتمد واجهة عربية من اليمين إلى اليسار، وتباينًا عاليًا، وأزرارًا لا يقل ارتفاعها عن 48 نقطة. تعتمد الهوية على كحلي داكن للخلفية، وأخضر زمردي للحالة الجاهزة أو التحديث الناجح، وعنبر للحالة قيد التحضير، وأحمر هادئ للمشكلات والتنبيهات.

| اللون | القيمة | الاستخدام |
|---|---:|---|
| كحلي الخدمة | `#0B1220` | خلفيات الشريط العلوي والحالات المركزة |
| زمردي القيصر | `#0E9F6E` | إجراءات الحفظ، الطاولة الشاغرة، والنجاح |
| عنبر المطبخ | `#D97706` | الطلب قيد التحضير أو يحتاج متابعة |
| قرمزي التنبيه | `#DC2626` | تعذر الحفظ والطاولات التي تحتاج انتباهًا |
| أبيض دافئ | `#F8FAFC` | خلفية المحتوى والبطاقات |

## قائمة الشاشات

| الشاشة | المحتوى والوظائف |
|---|---|
| ربط الكاشير | إدخال عنوان خادم الكاشير المحلي أو مسحه من رمز QR، ثم التحقق من الاتصال وحفظ العنوان محليًا. |
| دخول النادل | اسم المستخدم وكلمة المرور، مع حفظ جلسة محمية محليًا وإظهار اسم النادل بعد الدخول. |
| الطاولات | شبكة بطاقات كبيرة للطاولات تعرض المنطقة، المقاعد، والحالة: شاغرة أو مشغولة أو جاهزة للتقديم. يمكن فتح الطلب أو متابعته بلمسة واحدة. |
| الطلب | قائمة المنتجات والفئات والبحث، السلة، الملاحظات، ربط الطاولة، وحفظ التغييرات وإرسالها للمطبخ. لا ينفذ التطبيق دفعًا أو إلغاء فاتورة. |
| تفاصيل الطاولة | ملخص الطلب المفتوح وحالة المطبخ وتحديثها إلى تم التقديم، مع خيار الانتقال إلى تعديل الطلب. |
| الملف والإعدادات | حالة الشبكة المحلية، تبديل الوضع الداكن، تغيير عنوان الخادم، وتسجيل الخروج. |

## المسارات الأساسية

**بدء طلب صالة:** يسجل النادل الدخول ← يضغط طاولة شاغرة ← يختار فتح طلب ← يضيف أصنافًا وملاحظات ← يحفظ ويرسل للمطبخ ← تعود الطاولة مشغولة وتظهر حالة الطلب.

**متابعة الطلب:** يضغط النادل طاولة مشغولة ← يعرض حالة الأصناف ← يختار تعديل الطلب لإضافة أو حذف صنف ← يحفظ التعديلات ← يحدّث التطبيق بطاقة الطاولة.

**تقديم الطلب:** يفتح النادل تفاصيل الطاولة عندما تكون حالة المطبخ جاهز ← يضغط تم التقديم ← تصبح حالة الطلب محدثة في الكاشير والمطبخ.

**تهيئة الاتصال:** يفتح النادل الإعدادات ← يدخل عنوان IP المحلي للكاشير والمنفذ ← يتحقق من الاتصال ← يدخل بحسابه. لا يتم تخزين كلمات المرور الخام على الجهاز.

## قرارات تشغيلية

لن يتصل التطبيق بخدمة سحابية؛ يطلب خادم الكاشير الذي يعمل في وضع الشبكة المحلية فقط. لذلك تبقى البيانات لدى المطعم ويعمل التطبيق عندما يكون الهاتف والكمبيوتر على شبكة Wi‑Fi الخاصة نفسها. تظل عمليات الدفع، الخصومات الحساسة، والإلغاء في الكاشير المكتبي لحماية الصندوق.
