تحديث CAESAR POS اليدوي — Windows
==================================

إصدار الحزمة
------------

يبني المورّد نسخة Windows ويختبرها قبل النشر. ينتج البناء ZIP كاملًا لعميل جديد وZIP تحديث منفصلًا لتثبيت قائم. لا يحتوي ZIP التحديث رخصة عميل أو مولّد تراخيص أو مفتاحًا خاصًا أو بيانات تشغيل.

تسليم الرابط
------------

يرفع المورّد ملف CAESAR_POS_Update_v*.zip كأصل في GitHub Release، ويرسل للعميل رابط تنزيل ذلك الملف مباشرة. الرابط ينزّل ZIP فقط؛ لا يثبت التحديث تلقائيًا ولا يحتاج التطبيق إلى الاتصال بـGitHub.

خطوات العميل
-------------

1. أغلق CAESAR POS وخذ نسخة احتياطية معتادة من Vault.
2. نزّل ZIP وفك ضغطه كاملًا إلى مجلد مؤقت.
3. شغّل Apply_CAESAR_Update.bat، واختر مجلد التثبيت الذي يحتوي CAESAR_POS.exe.
4. بعد رسالة النجاح، شغّل النظام يدويًا من اختصاره أو من CAESAR_POS.exe.

سلوك الحماية
------------

يتحقق المُحدّث من أسماء ومسارات الملفات، ويوقف CAESAR_POS.exe في مجلد التثبيت المختار فقط، ثم يستبدل ملفات الحزمة مع نسخ مؤقتة للملفات المستبدلة والتراجع عند الفشل. لا ينسخ أو يحذف CAESAR_Vault أو الترخيص المحلي أو قاعدة SQLite أو ملفات WAL/SHM أو النسخ الاحتياطية أو السجلات، ولا يحذف الملفات التي غابت عن ZIP ولا يشغّل التطبيق تلقائيًا.

استثناءات JSON محددة للمكتبات الثابتة فقط: `app/factory_data.json` وملف `pythonnet/runtime/Python.Runtime.deps.json` بمسارات OneFolder المعروفة. أي JSON آخر يُستبعد، بما فيه إعدادات المطعم والرخص.

هذه الحزمة مخصصة لتحديث البرنامج لا لاستبدال نسخة احتياطية. اختبر التثبيت على Windows قبل إرسال رابط ZIP.

ملاحظة الثقة
------------

يتحقق المُحدّث من سلامة الملفات أثناء النسخ، لكن إصدار 4.0.1 لا يوقّع ZIP التحديث بتوقيع ناشر مستقل يتحقق منه العميل. أرسل فقط رابط الأصل الرسمي من GitHub Releases، واحمِ حساب GitHub بمصادقة متعددة العوامل ولا تستبدل الأصل بعد نشره.
